# Disagreement reason labelling

A labelling page for one question: when two annotators give the same Reddit comment (r/changemyview) different stance labels, why do they disagree? Reasons follow the four main categories of Sandri et al. (2023), *Why Don't You Do It Right? Analysing Annotators' Disagreement in Subjective Tasks* (EACL): human error, missing context, ambiguity and subjectivity.

Labels are kept in the labeller's browser. When `config.json` holds a `sheetUrl`, each label is also sent to the study's Google Sheet as it is saved. The page can always export the labeller's own labels as a CSV.
